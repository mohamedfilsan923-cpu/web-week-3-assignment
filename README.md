# Personal Budget Tracker (Visual Design Challenge)

This project is part of the Power Learn Project (PLP) Software Engineering Training. The objective of Week 3 is to enhance the visual design of the existing Budget Tracker using CSS.

## What Was Built
- **Intentional Color Palette:** Applied a cohesive indigo and slate color scheme consistently across page headers, buttons, and table headers.
- **Typography:** Integrated Google Fonts (`Outfit` for headings and `Inter` for body copy) to create a clear visual hierarchy.
- **Table & Form Styling:** Styled form inputs, buttons, table cells with proper padding, and alternating row colors for the expense table.
- **CSS Box Model:** Used margins, padding, borders, and `border-radius` to structure the layout into distinct visual cards (Header, Form, and Expense Table).

## File Structure
- `index.html`: Contains the structural layout of the application.
- `style.css`: Contains custom CSS variables, layout positioning, box model styling, and typography rules.
- `README.md`: Project documentation explaining the design implementation.
